# 📁 Commands — DIO Explorer

Slash commands disponíveis no projeto `dio_explorer`.

| Comando | Descrição | Arquivo |
|---------|-----------|---------|
| `/trilha <tecnologia>` | Retorna plano de estudos formatado da trilha escolhida | [trilha.md](./trilha.md) |
| `/desafio <tecnologia> <nivel>` | Gera um desafio de código aleatório por nível e tecnologia | [desafio.md](./desafio.md) |
| `/certificado <nome> <curso>` | Gera um certificado fictício em Markdown | [certificado.md](./certificado.md) |

---

## Como usar

Cada arquivo `.md` desta pasta descreve o comportamento, o template de saída e exemplos de uso do respectivo slash command.
